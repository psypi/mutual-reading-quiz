새로운 만남, 새로운 질문

이름을 붙여 독서 대결 방을 열어요

방을 만들면 P1으로 바로 입장합니다. P2에게 방 초대 링크를 보내 주세요.

다른 기기와 함께하려면 두 사람 모두 같은 서버 주소로 접속하세요. 초대 링크는 방을 만든 주소를 사용합니다. localhost 링크는 만든 기기에서만 열립니다.

P1 전용

내가 만든 방

이 브라우저에서 만든 방만 표시됩니다. 방을 해체하면 초대 링크로 다시 입장할 수 없습니다.

독서 대결

01

대기실

어떤 이름으로 함께할까요?

서버 접속 확인

상대 초대 대기 중

두 사람이 입장하고 준비를 완료하면 시작합니다.

P2 전용 초대 링크

현재 접속 주소 를 사용합니다. 다른 기기는 Mac의 LAN 주소로 접속해야 합니다.

초대 링크를 확인하고 있어요.

접속 상태를 2초마다 확인합니다. 시작 전 연결이 끊기면 준비가 해제되고, 시작 후에는 제출한 내용을 보존합니다.

02

내가 출제자

상대에게 건넬 질문

기준·핵심 답은 나만 보기

상대가 읽을 책과 범위를 정하고 질문을 만들어 주세요. 제출하면 수정할 수 없습니다.

출제자 전용 메모

아래 내용은 상대에게 전송되지 않습니다. 결과 공개 후에도 나만 볼 수 있어요.

상대에게는 책·범위·질문만 공개됩니다.

03

04

사람이 직접 평가해요

상대의 생각에 피드백을 남겨요

내가 낸 문제와 기준에 맞춰 평가해 주세요. 양쪽 평가가 끝날 때까지 상대가 준 점수는 공개되지 않습니다.

내 질문 · 핵심 답 · 채점 기준 확인

상대가 제출한 답변

아직 답변이 도착하지 않았어요.

평가는 한 번만 확정할 수 있습니다.

05

두 사람의 읽기가 만나는 순간

대결 결과

두 사람이 평가를 마치면 점수와 피드백을 함께 공개합니다.

방이 종료되었어요

이 방은 해체되었습니다.

방을 만든 사람이 종료하여 더 이상 입장하거나 진행할 수 없습니다.
